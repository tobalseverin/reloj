# Reloj

Reloj web con tres vistas: analógica, digital con milésimas y comparador de zonas horarias.
Es una pieza de portfolio mínima, en blanco y negro, con un duotono opcional.

```bash
pnpm install
pnpm dev
```

Para el build estático, `pnpm build` genera `dist/`.
La planificación está en `PLAN.md`, `DISENO.md` y `ARQUITECTURA.md`.
